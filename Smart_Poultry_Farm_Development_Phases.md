# Smart Poultry Farm Automation System -- Development Phases

## Project Overview

Build a cross-platform smart poultry farm management application
using: - **Frontend:** Flutter - **Backend:** Node.js (Express.js) -
**ORM:** Sequelize - **Database:** MySQL - **IoT:** ESP32 with sensors -
**AI:** Python Computer Vision

The system automates feeding, water supply, environmental monitoring, AI
health detection, and provides an online marketplace for poultry sales.
